**Fits the term because:** it's a standing requirement for every Autumn term, regardless of that term's own focus badge — a short, local orienteering session run in the park, separate from the term's badge work.

**Badge focus:** none currently mapped — placeholder only.

**Status: placeholder.** This is a stub, not a delivered session — details (running order, course design, materials, any badge tie-in) are still to be filled in.
