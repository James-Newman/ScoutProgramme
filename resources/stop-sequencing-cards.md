# STOP Sequencing Cards

Used in: [Outdoor Safety & Risk Awareness](../year-1/term-2/outdoor-safety-and-risk-awareness.md) ("Safety induction: hazard cards, buddy check, STOP", 6 min). Print 6 sets (one per patrol), shuffle each set before handing it out. Each set is 4 cards.

| Card | Word | Description |
| :-- | :-- | :-- |
| 1 | **S** — Stop | Stay where you are. Don't wander further. |
| 2 | **T** — Think | What do you know? What do you need? |
| 3 | **O** — Observe | Look around for a landmark or a way back. |
| 4 | **P** — Plan | Decide what to do, then do it. |

Patrols race to arrange the four cards in the correct order (S, T, O, P), then the whole room reads the sequence aloud together once.
