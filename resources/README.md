# Resources

Printable materials for Year 1's sessions (Term 1 and Term 2) that don't already exist as a ready-made official download. Each file names the session it's for and, where relevant, the real activity it adapts.

This directory only covers **informational/printable materials** (cards, templates, checklists, posters) — not physical equipment. Tents, mallets, firewood, rucksacks, and similar gear can't be "made"; they need sourcing, and are listed as-is in each term's `overview.md` material inventory.

## Real official resources used instead of a local copy

Some printable materials already exist as an official download and don't need recreating here — link to these directly rather than duplicating them:

- **Emergency scenario cards & bingo grid** (for [Outdoor Safety & Risk Awareness](../year-1/term-2/outdoor-safety-and-risk-awareness.md)'s "Emergency scenario bingo") — [Emergency Bingo PDF](https://prod-cms.scouts.org.uk/media/4583/ready-to-respond-emergency-bingo.pdf) and the alternative [Emergency Guess Who PDF](https://prod-cms.scouts.org.uk/media/4584/ready-to-respond-emergency-guess-who.pdf), both from the official [Emergency scenario bingo](https://www.scouts.org.uk/activities/emergency-scenario-bingo/) activity page.
- **The Countryside Code** (for [Night Hike](../year-1/term-2/night-hike.md)) — official leaflets and posters at [gov.uk/countryside-code](https://www.gov.uk/countryside-code).
- **Camp kit list** (source list for `kit-list-bingo-cards.md`) — the official [Scouts Camp Kit List](https://shop.scouts.org.uk/journal/2024/05/17/scouts-camp-kit-list).
