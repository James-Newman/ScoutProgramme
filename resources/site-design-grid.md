# Site Design Grid

Used in: [Site Layout & Design](../year-1/term-1/site-layout-design.md) ("Design your site", 35 min). Print one grid per patrol, plus a set of the counter labels below (cut out, or substitute with your own icon stickers).

## The grid

A 10×10 empty grid representing "the field." Draw it on plain paper or print squared paper — the exact size doesn't matter, as long as every patrol has the same size grid to work with. Mark one edge as "prevailing wind direction" and one corner as "site entrance" before handing it out, so every patrol is designing against the same constraints.

## Counter labels (cut out one set per patrol)

| Label | What it represents |
| :-- | :-- |
| Sleeping tent ×2 | Where patrol members sleep |
| Mess tent | Shared eating/shelter space |
| Fire circle | Where the fire or stove goes |
| Kitchen | Food prep and cooking area |
| Food/kit store | Where shared equipment and food are kept |
| Eating area | Where the patrol sits to eat |
| Latrine/wash area | Furthest from the kitchen and sleeping tents |

Patrols place the labels on their grid, reasoning out loud about wind direction, slope, and distance between the fire and the tents, per the [well-organised site requirement](../year-1/term-1/site-layout-design.md).
